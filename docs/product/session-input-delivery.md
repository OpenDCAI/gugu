# 排队发送与等待接收

排队发送由输入框负责。输入框知道 agent 正在执行时，用户提交的新消息先保留在发送队列，从第一帧就显示在输入框上方的排队区，不先显示成对话气泡。编辑、删除、拖动排序、立即发送继续在排队区使用；消息实际发出时才进入对话。编辑期间保留原草稿、附件和队列位置，不自动发出；保存或取消后恢复原草稿。

已经发出的消息由 agent 接收。agent 暂时忙碌或正在压缩上下文时，消息留在对话原位，属于等待接收，不退回发送队列，也不提供队列操作。发送中沿用气泡旁的转圈小圆点，等待接收在同一位置换成三个波浪起伏的点；接收后指示消失。两个指示都不加可见文字、不新增一行、不占额外高度，回执和原生回显不得使消息消失、重复或上下移动。

真失败与结果不确定保留原有说明及适用的重试能力；离线时已确认的“等待发送”表现保持不变。显示状态的变化不改变消息实际执行时机。这样用户能分清尚未发送和已发待接，也不会把位置跳动误认为消息丢失或又发了一次。
