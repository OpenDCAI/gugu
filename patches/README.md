# Dependency patches

`ssh2@1.17.0.patch` fixes how an SSH channel resumes writes that waited for the peer's window. Upstream kept the resumed stdout chunk and, once stderr also waited, wrote that old stdout chunk again instead of the stderr data. On the remote tunnel's embedded SSH server this repeated bytes inside the device link's frame stream, and the desktop dropped the link with `frame too large`. The patch clears both waiting writes before resuming them and resumes stdout and stderr. Remove it when a published ssh2 contains the same fix, after `ssh2WindowResume.test.ts` passes without it.

`@codemirror__autocomplete@6.20.3.patch` gives the completion view plugin a `destroy()` that clears its debounce timers and aborts its running queries. Upstream (still in 6.20.4) has none, so a typing debounce scheduled before `view.setState()` fires against the new state; when that state has no autocompletion (the file editor with no file open) it throws `RangeError: Field is not present in this state`. Remove it when a published @codemirror/autocomplete destroys its timers, after the "a file swapped out mid-word" case in `codemirror-diff-model.test.ts` passes without it.
