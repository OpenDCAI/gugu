# 功能短片素材

三段离线 WebM 是引导设计的连续动画导出，使用匿名化的产品 DOM/CSS 及依据组件源码补充的交互状态；不是实时操作用户账号，也不是产品验收录像。项目、聊天与联系人信息均为示例内容。画面不裁切应用工作区，包含动画指针；WebP 为首帧封面，VTT 为随片字幕。设计规范第 7 节要求的真实 Electron 录屏仍待替换；这些动画不能作为该项通过的依据。

1280 × 788，15 fps，VP8（yuv420p，偶数尺寸），无音轨。保留片段为 feature-1（列表/页签拖出分栏）、feature-3（添加联系人）与 feature-4（Agent 工作汇报），视频、封面和 VTT 必须按同一编号配对。旧交互模式片段及其字幕已移除。播放控制与多语言说明由 `components/productTour` 承担。素材按需加载，不依赖网络。
