# 会话页扩展示例

> 界面上叫 App；目录名和代码里仍叫 extension。

每个目录是一个可以直接装的 bundle:`manifest.json` + 自带的 HTML 页面。装法:

```
gugu_session app_install source_dir=examples/extensions/<slug>   # agent 自己装(仅限零权限那些)
```

在设置的「App」一栏里从文件夹安装,可以装任何一个(要权限的那几个由人过目后同意)。

只留真的有用的(owner 2026-09-14:「目前哪有这么多真的有用的 extension」)。原先十个示范各种能力的玩具
(番茄钟、字数统计、色板、i18n 对照、SQL 片段、依赖图、HTTP 探针、文本 diff)已删——能力的示范由文档承担,
不靠一堆没人会装的扩展撑清单。

## 运行条件

CSP 不许内联脚本、主题变量用 `--em-*` 这些运行条件只在产品内 guide 里写(`apps-ui` 与 `apps` 两篇,原文
`apps/desktop/src/session/shared/extensions/authoring-guide.ts`),这里不另写一份。

## 现在有的

| 目录 | 它是什么 |
| --- | --- |
| `regex-forge` | 正则工作台。零权限;带图标、README、CHANGELOG,是发布到市场的参照实现 |
| `standup-board` | 扫代码里的 TODO / FIXME 成看板,一键放进当前对话的输入框,你发给 agent 接着办(`compose` 的用法) |
| `session-lens` | 「扩展一律 app 级」的示范:整个 app 一张页,切项目 / 会话只重画不重建;照出当前项目、会话与最近 10 条用户消息 |
| `cache-keeper` | 本地 App 的示范:钟在后台页里走(没人开着也走),替勾上的会话在提示缓存凉掉前发一轮最便宜的 ping;ping 失败或会话报错就退让,报错停下的会话排队续上 |
| `ext-debug` | **不是给人用的,是仪器**:把桥上每个动词当场跑一遍,谁挂了就把错误原文摊出来;唯一申请全部能力的那个。❌ 不发布到市场 |

`ext-debug` 单独说一句。普通示例各自只用两三个动词,失败时又都长着自己的空态——
于是「桥坏了」和「这里确实没东西」长得一模一样,bug 就藏在这中间(真发生过两次,最后是
人手点出来的)。它申请了全部能力(含 agent 的看状态/读对话/控制三档,都取全局)和一个网络域名,只为把每一条路都走一遍;
换会话、换项目、同项目换另一个会话之后打开它,绑定要是出了问题,那几个格子会直接把原话写在脸上。

权限一栏值得单独说:`regex-forge` **什么都不要**,照样是这几个里最好用的一个;其余几个也只要
它们真的会用到的那几项——仓库里有一条判据盯着这件事:声明了却不用,就是在向用户多要。
